# writing-conventional-commits

按 [Conventional Commits 1.0.0](https://www.conventionalcommits.org/) 写 git commit message。个人 skill 也可放在 `~/.cursor/skills/writing-conventional-commits/`。

## 行为

- Header：`type(scope): description`
- Body 可选
- 破坏性变更：header 加 `!`
- 用户说「提交」后先出示消息，确认后再 `git commit`

主指令见 [SKILL.md](SKILL.md)。
